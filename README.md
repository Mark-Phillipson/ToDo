# Local Snippets Manager
Local first Snippets Manager with a multi-line dictation box for composing longer snippets by voice.

## Stand-alone Blazor Web Assembly PWA

This repository contains a Blazor WebAssembly progressive web app (PWA) for capturing and retrieving local snippets stored locally in the browser.
